# ResearchPro Academic Services website

This is a responsive static website prepared from the supplied ResearchPro content and brand details.

## Preview

Open index.html in a modern browser. The site has no build step or external library dependency.

## Included

- Home, About, Services, Publication, Authorship, Insights, Policies, and Contact pages
- Responsive multi-level navigation
- Right-side contact tab, social links, and slide-in contact panel
- WhatsApp enquiry flow for contact forms
- Article enquiry draft addressed to the supplied email
- Searchable research-area and insight cards
- Supplied ResearchPro logo artwork and social links

## Form behavior

Contact forms open WhatsApp with a prefilled message. The visitor reviews and sends it from WhatsApp. Article enquiries open the visitor's email app; an optional selected file is not uploaded by this static site and must be attached manually. No form submissions or manuscripts are stored by the website.

## Before public launch

Confirm the contact email address, office address, response expectations, and legal-policy wording. Add a secure server-side submission service before collecting manuscript files directly through the site. No journal directory records were supplied, so the journal page currently offers journal-selection guidance without listing or claiming indexing for specific titles.
